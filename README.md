# imamfikri.github.io

Personal portfolio. Two case studies in operations tooling and product.

**Live:** https://imamfikri.github.io

## What's here

A single self-contained HTML page. No build step, no framework, no dependencies beyond
webfonts. Editing `index.html` and pushing is the entire deployment process.

```
index.html          the whole site
images/             screenshots, redacted
```

## Case studies

**Creator Discovery Lab** — a KOL discovery and content operations platform I designed, built
and operate at HeyRCG with no engineering team. The write-up covers the problem reframe, the
five product decisions behind it, and the performance work that took the dashboard from a 68
second load to 0.35 seconds.

**Ekta** — a field canvassing app and monitoring dashboard I ran product for at Satu Teknologi
Digital, which logged over 500,000 activities in six months.

## A note on the screenshots

Every image here is redacted. Creator identities, client brand names and per-client commercial
performance are blurred or cropped, because the underlying system holds real data about real
people and real client accounts. What remains visible is the structure and the decision logic,
which is the part worth showing anyway.
